# Sprice Private

Одностраничный сайт приватного софта и макросов. Один файл, без сборки и без зависимостей — только Google Fonts по ссылке.

## Что внутри

| Раздел | Описание |
|---|---|
| Каталог | 5 продуктов с иконками, тегами, ценами и тарифами |
| Страница продукта | Галерея скриншотов, «Что внутри», «Характеристики», выбор тарифа |
| Тарифы | Модалка с планами и переходом на оплату в FunPay |
| Аккаунты | Регистрация и вход, профиль с историей заказов |
| Язык | Переключатель RU / EN, выбор сохраняется |
| Тема | Тёмная и светлая, выбор сохраняется |

## Запуск

Скачай `index.html` и открой двойным кликом в браузере. Всё работает локально:

- интернет нужен только для шрифтов Google Fonts;
- аккаунты и заказы хранятся в `localStorage` браузера — сервера нет;
- пароль хранится зашифрованным (PBKDF2-SHA256, 100 000 итераций), в открытом виде не сохраняется.

|---|---|---|

## Устройство

Всё в одном `index.html`: `<style>` в `<head>`, разметка, один `<script>` в конце. Данные продуктов, скриншоты (base64) и словарь переводов лежат в JS-объектах, карточки строятся скриптом. Страница продукта открывается по хешу `#p=<id>` — поэтому работает кнопка «Назад» в браузере.
